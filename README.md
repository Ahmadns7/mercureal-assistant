# mercureal-assistant

Siri, but private and offline. A voice assistant for Android that runs entirely on your phone.

Speech is transcribed by whisper.cpp, the reply is generated by a small quantized llama.cpp model, and the answer is spoken by an on-device sherpa-onnx voice. No system or cloud TTS is used; if the voice is not installed, the app reports an error instead of speaking.

## Conversation mode

After the assistant answers, it keeps listening for your next question without a wake word, for a follow-up window you choose in Settings (30, 60 or 120 seconds of silence ends it, default 60). Turn it off in Settings and only hold-to-talk or the wake word start a turn. Pressing hold-to-talk or a new wake word interrupts an open window. The mic is never shared: the wake-word listener releases it while a conversation turn holds it, and it ignores its own spoken replies for a short echo guard.

Turn detection is an energy-based voice activity gate (no extra model, no new permission). It works on a quiet room. It can misfire in loud rooms or with TV or music playing. Silence and speech thresholds are constants in VoiceActivityCapture.kt.

The home screen shows the current state: listening, listening for your next question, thinking, speaking.

## Notes ("remember that ...")

Say "remember that <note>" to save a note on this phone. Say "what do you remember about <topic>" or "my notes" and the matching notes are added to the model's context for that answer only. Notes are stored in app-private DataStore (one JSON file), are never uploaded, and are cleared when you clear app data. Settings > Notes lists them, with delete per note and delete all. The assistant only uses notes when you ask about them, and it says so when none of them answer the question.

## Privacy and network use
- The app declares RECORD_AUDIO and INTERNET. INTERNET is used for one thing only: downloading the model files you choose in Settings > Models. Nothing else in the app gets network access. Speech, prompts, transcripts and replies never leave the phone, and there is no analytics or crash reporting.
- Downloads are fetched over HTTPS from pinned Hugging Face commits. Each file must match its pinned size and sha256 before it is accepted. Interrupted or cancelled downloads keep their partial file and resume from it on the next attempt (HTTP Range). A size or checksum mismatch deletes the partial file.
- Models are stored in the app's private internal storage (filesDir/models), not on external or shared storage. Delete a model in Settings > Models to free its space.

Status: v0.3.0 (device commands, widget, quick settings tile added). Models screen added, resumable model downloads. The native pins and Kotlin/JNI signatures were reviewed statically, but the app has NOT been compiled with the Android toolchain or run on a device yet. Expect first-build friction.

## Stack
- Kotlin + Jetpack Compose UI (push-to-talk, minSdk 26, arm64-v8a)
- whisper.cpp via JNI: STT, default model ggml-tiny.en
- llama.cpp via JNI: LLM, default model Qwen2.5-0.5B-Instruct Q4_K_M
- sherpa-onnx 2.0.0 (prebuilt arm64 AAR, pinned sha256) for offline TTS: VITS LJSpeech int8 voice, about 37 MB, downloaded in Settings > Models. No system TTS.

## Setup
1. `./scripts/setup_native.sh` to vendor whisper.cpp (v1.7.6) and llama.cpp (b5957) under third_party/, pinned to tags verified against the JNI sources.
2. Open the project in Android Studio (or `./gradlew assembleDebug`) and install on an arm64 device. Requires JDK 17, Android SDK with NDK 27.0.12077973 and CMake 3.22.1. Gradle 8.13, AGP 8.13.2, Kotlin 2.2.21.
3. Open Settings > Models, download a speech model (tiny.en, base.en or small.en) and a language model (Qwen2.5 0.5B or Llama 3.2 1B, both Q4_K_M), then tap "use" on the one you want. Your choice is saved.
4. Hold "hold to talk", speak, release.

Curated models (all pinned to a specific Hugging Face commit):
- STT: whisper.cpp ggml tiny.en (about 78 MB, MIT), base.en (about 148 MB, MIT), small.en (about 488 MB, MIT). Source: ggerganov/whisper.cpp.
- LLM: Qwen2.5-0.5B-Instruct Q4_K_M (about 491 MB, Apache-2.0). Source: Qwen/Qwen2.5-0.5B-Instruct-GGUF.
- LLM: Llama-3.2-1B-Instruct Q4_K_M (about 808 MB, Llama 3.2 Community License). Source: bartowski/Llama-3.2-1B-Instruct-GGUF.

## Wake word ("ahmad")

Always-on keyword spotting runs fully offline with sherpa-onnx KWS (zipformer, zh-en 3M, int8 encoder, chunk-16, about 5.4 MB kept after extraction). It is off by default. Turn it on in Settings or on the main screen once the "Wake word" model is downloaded in Models.

Keywords are phoneme lines in app/src/main/assets/wake/keywords.txt (AA1 M AA1 D and AH0 M AA1 D, plus AH0 M EH1 D and AA1 M AE1 D alternates). Tuning is a file swap: change the lines, rebuild.

While on, a foreground service with a persistent "Mercureal wake word on" notification keeps the microphone open (foregroundServiceType=microphone). Only the small KWS model runs continuously. On a hit it captures up to 6 seconds of speech (or stops after about 0.9 seconds of silence) and hands that audio to the existing whisper, llama and TTS path. If the keyword model or keywords file is missing, the service fails closed and the toggle switches back off.

Battery: the KWS loop is one CPU thread running continuously with the mic open. No battery measurement has been taken yet.

## Archive model downloads

Some models ship as archives (tar.bz2 or zip). ModelDownloader streams the archive, extracts only the members pinned in ModelCatalog, and verifies each extracted file's size and sha256 individually before moving it into place. Any mismatch deletes every file for that model and fails closed. The archive itself is deleted after extraction.

## Device commands (voice)

Say one of these and the phone does it with a standard Android app. Each reply is spoken and shown on screen. Anything that does not match falls through to normal chat.

- "set an alarm for 6am" or "set alarm for 6:30 pm": ACTION_SET_ALARM, with the clock app's skip-UI flag so it sets silently.
- "set a timer for 10 minutes" (seconds, minutes or hours): ACTION_SET_TIMER.
- "call <contact name>": looks the number up in your contacts and opens the dialer with it. Nothing is placed automatically; you tap call. A raw number like "call 0801 234 5678" skips the lookup. If several contacts match, it lists them and asks for the full name.
- "open <app>": launches a curated list (WhatsApp, YouTube, Chrome, Gmail, Maps, Spotify, Settings, Play Store, Photos, Calendar). Any other app opens the system app chooser so you pick it.
- "add reminder <text> at 5pm" or "... in 10 minutes": a local notification scheduled with AlarmManager (setExactAndAllowWhileIdle when exact alarms are allowed, otherwise an approximate alarm and the app says so). With no time spoken, it asks when.

Everything is resolved on the phone with public intents. No network is used.

Permissions added for these features, and why:
- READ_CONTACTS: only for "call <name>", to find the number. Requested the first time you ask. Contacts are not stored or sent.
- POST_NOTIFICATIONS (Android 13+): to show the reminder notification. Requested when you first set a reminder.
- SCHEDULE_EXACT_ALARM: so reminders fire on the minute. You can revoke it in system settings; the app then uses approximate timing.
- A <queries> block listing the 10 curated app packages, so the app can see whether they are installed. No other app list is read.

## Home screen widget and quick settings tile

- Widget "Mercureal listen": one "tap to talk" button. Tapping it opens the app in listening mode and starts one turn. This is the tap fallback: widgets cannot receive press-and-hold, so the button does not hold the mic. The widget is plain RemoteViews, not Glance, to avoid adding a dependency.
- Quick settings tile "Mercureal listen": add it from the notification shade edit panel. Tapping it does the same as the widget. It does not keep the mic open in the background.
Both launch MainActivity with the LISTEN action. They do not add any permission.

## Multilingual speech and translation

- Speech: `whisper-tiny` and `whisper-small` (ggml, multilingual) are in Models. In Settings, pick a speech language or leave it on auto (detection). English-only `.en` models always listen as English.
- Translation: turn on Translation in Settings, then say "say <text> in french" or "translate <text> to spanish". The on-device Qwen LLM does the translation, so no extra model or permission is needed. Quality for small languages (yoruba, hausa, swahili) depends on the 0.5B model and is not verified.
- Speech output: the bundled voice (vits-ljs) is English-only. Non-English translations are shown on screen and the app says so aloud.
