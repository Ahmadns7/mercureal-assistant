# mercureal-assistant

Siri, but private and offline. A voice assistant for Android that runs entirely on your phone.

Speech is transcribed by whisper.cpp, the reply is generated by a small quantized llama.cpp model, and the answer is spoken with the on-device TTS engine.

## Privacy and network use
- The app declares RECORD_AUDIO and INTERNET. INTERNET is used for one thing only: downloading the model files you choose in Settings > Models. Nothing else in the app gets network access. Speech, prompts, transcripts and replies never leave the phone, and there is no analytics or crash reporting.
- Downloads are fetched over HTTPS from pinned Hugging Face commits. Each file must match its pinned size and sha256 before it is accepted. A failed or mismatched download is deleted.
- Models are stored in the app's private internal storage (filesDir/models), not on external or shared storage. Delete a model in Settings > Models to free its space.

Status: v0.2.0 scaffold. Models screen added. The pipeline is wired end to end, but it has not been built or run on a device yet. Expect to fix native build issues on first compile.

## Stack
- Kotlin + Jetpack Compose UI (push-to-talk, minSdk 26, arm64-v8a)
- whisper.cpp via JNI: STT, default model ggml-tiny.en
- llama.cpp via JNI: LLM, default model Qwen2.5-0.5B-Instruct Q4_K_M
- Android TextToSpeech for output (see TODO in Tts.kt about offline voices)

## Setup
1. `./scripts/setup_native.sh` to vendor whisper.cpp and llama.cpp under third_party/.
2. Open the project in Android Studio (or `./gradlew assembleDebug`) and install on an arm64 device.
3. Open Settings > Models, download a speech model (tiny.en, base.en or small.en) and a language model (Qwen2.5 0.5B or Llama 3.2 1B, both Q4_K_M), then tap "use" on the one you want. Your choice is saved.
4. Hold "hold to talk", speak, release.

Curated models (all pinned to a specific Hugging Face commit):
- STT: whisper.cpp ggml tiny.en (about 78 MB, MIT), base.en (about 148 MB, MIT), small.en (about 488 MB, MIT). Source: ggerganov/whisper.cpp.
- LLM: Qwen2.5-0.5B-Instruct Q4_K_M (about 491 MB, Apache-2.0). Source: Qwen/Qwen2.5-0.5B-Instruct-GGUF.
- LLM: Llama-3.2-1B-Instruct Q4_K_M (about 808 MB, Llama 3.2 Community License). Source: bartowski/Llama-3.2-1B-Instruct-GGUF.

## Roadmap
- Real hotword / wake word (currently push-to-talk only)
- Verify and bundle a fully offline TTS voice
- Streaming LLM output and barge-in
- Tool intents on-device (timers, notes, reminders) without network
- Pin whisper.cpp and llama.cpp to tested tags
- Checksums for the native submodules, and an on-device check that a model file loads before it is marked active
